Настройка доступа к GitHub (Для Тамары)

Чтобы публиковать изменения прямо из браузера (без сторонних программ и без Git), укажите один раз ваш GitHub Personal Access Token. Он будет надёжно сохранён в вашем браузере.

Токен генерируется в GitHub: Settings → Developer Settings → Personal access tokens → Tokens (classic) с галочкой repo.
